# ADR 0003 — Cloudflare Realtime TURN for WebRTC relay

- Status: Accepted (2026-10-16); amended by [ADR 0010](0010-online-matches.md): the credentials come from a
  Next.js route with Vercel env vars instead of a Cloud Function

## Context
The multiplayer games (Tavla, Naval Strike, Number Detective, Tito) currently use Ably, with Ably keys exposed in the client. The platform will build its own multiplayer layer; players behind NAT/CGNAT need TURN.

## Decision
- The platform (top-level page) owns the connection: WebRTC DataChannel, with signaling over the Firebase Realtime Database.
- TURN: Cloudflare Realtime TURN. Short-lived ICE credentials are generated by a `getIceServers` Cloud Function via
  `rtc.live.cloudflare.com/v1/turn/keys/{KEY_ID}/credentials/generate-ice-servers`; the token lives in Secret Manager.
- Port 53 URLs are filtered out before credentials reach the client.
- If WebRTC cannot connect, moves are relayed through RTDB (fallback channel).

## Consequences
- Cost: first 1,000 GB per month free, then ~$0.05/GB (re-check current pricing during implementation).
- The Ably dependency is removed entirely in import wave 3.
